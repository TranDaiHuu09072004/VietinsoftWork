# HPA Controls & Grid Guidelines

## 1. Input & Grid Controls
- **hpaControlDate**: Input/Select date. Grid format: `yyyy-MM-dd` -> `dd/MM/yyyy`.
- **hpaControlTime**: Select time (`HH:mm`).
- **hpaControlDateTime**: Date & time. Grid format: `yyyy-MM-dd HH:mm:ss` -> `HH:mm:ss dd/MM/yyyy`.
- **hpaControlPhone**: Input phone number.
- **hpaControlNumber**: Numeric input only.
- **hpaControlMoney**: Currency input. Grid format: dot separator (e.g., `100.000.000`).
- **hpaControlFile**: File uploader.
- **hpaControlRichTextEditorPremium**: Word-like rich text editor.
- **hpaControlText**: Single-line text. Grid format: unchanged.
- **hpaControlTextArea**: Multi-line text.
- **hpaControlSelectBox**: Single-select dropdown. Grid format: display name of selected item.
- **hpaControlTagBox**: Multi-select tags.
- **hpaControlSelectEmployee**: Select employee popup. Grid format: employee name.
- **hpaControlCheckBox**: Checkbox (0/1). Grid format: checkbox element.

## 2. AI Code Generation & User Survey (ask_question)
Before generating SQL/UI code, the AI **MUST** use `ask_question` tool to survey the user:
- **For Input Form Fields** (3 questions):
  1. Control Type (Select from `hpaControl...` options).
  2. Input Label (Suggested name or custom text).
  3. Label Position (Top, Bottom, Left, Right, None).
- **For Grid Columns** (2 questions):
  1. Column Control Type (Select from `hpaControl...` options).
  2. Column Header (`DisplayName` text).
- *Fallback*: Use implicit mapping based on database field names only if the user skips or declines to answer.

## 3. Runtime Customization (JavaScript)
- **AutoSave / ReadOnly**: Override `tblCommonControlType_Signed` defaults at runtime (set **before** `loadUI` script execution):
  - `window._autoSave<ColumnName><UID> = true | false;`
  - `window._readOnly<ColumnName><UID> = true | false;`
- **Value Getter/Setter**:
  - *Standard wrapped controls*: Use `Instance<ColumnName><UID>.getValue()` and `.setValue(val)`.
  - *Raw DevExtreme widgets* (e.g. `hpaControlDate`): **Must** use `.option("value")` and `.option("value", val)`.

## 4. Title & Validation (DisplayName)
- **Grid Column**: `DisplayName` sets the column header text.
- **Input Form**: UI labels are regular HTML `<label>` tags. `DisplayName` is **ONLY** used as the field name in validation error messages when `IsRequired = 1` (e.g., *"[DisplayName] is required"*).
